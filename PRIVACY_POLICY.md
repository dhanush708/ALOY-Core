# Privacy Policy

**Effective Date:** July 2026

Dhanush A ("Creator") developed **ALOY** as a local-first desktop application. This Privacy Policy explains our commitment to your privacy and how your data is handled.

---

## 1. Local-First Architecture (Zero Cloud Storage)
ALOY is designed to run entirely on your own computer. We believe your private thoughts, conversations, and workspace files should remain yours.
- **No Cloud Accounts**: ALOY does not require you to create an account, log in, or register to use the application.
- **Local Data Storage**: All your conversation history, project indexes, settings, and workspace memories are stored locally on your device in a local database file (`data/aloy.db`).
- **Local AI Processing**: Prompts and reasoning steps are processed locally on your computer using your own installed Ollama models. Your prompts are never transmitted to a cloud LLM service by the application.

## 2. No Analytics and No Telemetry
We do not track you.
- **No Telemetry**: ALOY does not collect, record, or transmit usage statistics, feature telemetry, crash logs, or performance reports to any external server.
- **No Advertisements**: The application does not contain advertising libraries or third-party trackers.

## 3. Internet Connectivity Limitations
ALOY does not connect to the Internet except in the following explicit scenarios:
- **User-Requested Web Search**: If you query ALOY with a prompt that requires live web search (for example, looking up current dates, new packages, or real-time news), the application will connect to public search engines (such as DuckDuckGo) to retrieve search snippets to answer your question. This network traffic is initiated strictly on-demand to fulfill your search request.
- **Local Package Documentation Fetching**: When indexing a specific software package documentation layer, the application may fetch public, official package pages to compile documentation index summaries.

No personal identifiers, conversation histories, or account credentials are included in these external search queries.

## 4. Data Security and Backups
Because ALOY stores all data locally on your machine, **you are solely responsible for the backup, recovery, and security of your database and workspace files**. The Creator does not have access to your database and cannot assist in recovering lost, deleted, or corrupted files.
